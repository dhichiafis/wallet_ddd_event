# wallet 
the wallet is a design best practices emulating the architecture patterns 
the architecture patterns used is the message bus to decouple the services and handled by the message bus 
the repository pattern that is responsible for persisting our domain models 
domain driven design where each aggregate is responsible for maintaining the business rule 
a clean implemenation of accounting systems that is double entry system
the wallet will be having features like withdrawal and transfers
